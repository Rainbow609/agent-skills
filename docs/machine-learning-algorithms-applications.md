## 0. 三条先记住

1. **先分任务，再选模型**：分类、回归、聚类、排序、密度估计、降维、优化是七类基本任务；同一任务可用不同范式（监督/无监督/强化）和不同模型（概率/几何/逻辑/网络）实现 `[原文]`。
2. **算法数量不是重点**：讲义明确说机器学习算法有数千种、每年新增数百种；真正要掌握的是「问题 → 任务 → 范式 → 模型」的映射，而不是背算法清单 `[原文]`。
3. **企业落地不是算法问题**：数据、技术、投入和「一把手工程」是前提；算法只在数据与业务目标清晰之后才有意义 `[原文]`。

## 1. AI / ML / DL 的定位

| 概念 | 讲义定义 | 关系 |
| --- | --- | --- |
| 人工智能（AI） | 研究感知外部环境并为某个目标采取行动的「智能体」 | 最大范畴 |
| 机器学习（ML） | AI 的一个分支，构建能从数据中学习的系统；用已有数据（经验）得出模型并预测未来 | AI 的子集 |
| 深度学习（DL） | 实现机器学习的一种技术；用多层处理层对数据做高层次抽象 | ML 的一种实现方式 |

讲义还强调：从数据到知识与能力，**能力增强是最终目标**；符号/统计/连接等不同方法应综合利用（该页为图片，具体三分法细节未提取到）`[原文，细节缺失]`。

## 2. 理解算法的三个视角（最可复用的框架）

面对一个新问题，依次回答三个问题 `[原文]`：

| 视角 | 回答的问题 | 内容 |
| --- | --- | --- |
| 学习任务（Learning Task） | 做什么 | 分类、回归、聚类、排序、密度估计、降维、优化 |
| 学习范式（Learning Paradigm） | 在什么条件下学 | 监督、无监督、强化 |
| 学习模型（Learning Model） | 怎么学 | 概率、几何、逻辑、网络 |

### 2.1 任务视角

| 任务 | 一句话定义 | 讲义给的典型算法 |
| --- | --- | --- |
| 分类 | 输入被划分到两个或多个已知类别 | SVM |
| 回归 | 输出是连续值而非离散值 | 贝叶斯线性回归 |
| 聚类 | 输入被划分为事先未知的组 | k-means |
| 排序 | 用排名替代原值的数据变换 | PageRank |
| 密度估计 | 寻找输入在某个空间中的分布 | Boosting Density Estimation |
| 降维 | 把输入映射到低维空间以简化 | Isomap |
| 优化 | 从所有可行解中找最优解 | Q-learning |

### 2.2 范式视角

| 范式 | 一句话定义 | 典型算法 |
| --- | --- | --- |
| 监督 | 用标注数据训练，对未见点做预测 | SVM |
| 无监督 | 只接收未标注数据，对未见点做预测 | k-means |
| 强化 | 与环境交互，每个动作获得回报 | Q-learning |

### 2.3 模型视角

| 模型 | 一句话定义 | 子模型与典型算法 |
| --- | --- | --- |
| 概率 | 用概率模型表示随机变量间的条件相关性 | 贝叶斯/贝叶斯网络、生成式概率规划、统计线性回归 |
| 几何 | 用线、面、距离或流形构造学习算法 | 线（线性回归）、面（SVM）、距离（k-NN）、流形（Isomap） |
| 逻辑 | 用逻辑模型构造学习算法 | 逻辑（归纳逻辑编程）、规则（关联规则） |
| 网络 | 用网络模式构造学习算法 | 浅层（感知机）、深层（CNN） |

## 3. 机器学习的一般流程与企业条件

**流程** `[原文]`：数据搜集 → 数据清洗 → 特征工程 → 数据建模。讲义把数据预处理单独展开，说明它是决定上限的环节。

**企业应用三个方向** `[原文]`：

- 生产：故障预测、流程优化；
- 运营：财务风险分析、供应链管理；
- 销售：客户行为分析、个性化推荐。

**落地前提** `[原文]`：数据、技术、投入，以及「一把手工程」。缺少组织层面的推动，算法项目很难跨部门拿到数据与业务配合。

## 4. 数据预处理

为什么需要预处理 `[原文]`：

- 采集时可能缺失、错误、不一致；
- 描述对象的数据未必能反映潜在模式；
- 属性可能很多，其中有无用或冗余的。

四类方法 `[原文]`：数据规范化（normalization）、数据离散化（discretization）、数据清洗（data cleaning）、特征提取与特征选择（feature extraction and selection）。

补充（来自配套 PdM 课程，见 `predictive-maintenance-data-analysis.md`）：标准化常用两种——零均值单位方差（适合接近正态的数据）与 0–1 缩放（适合无异常值的数据）；量纲大的特征会主导模型，因此缩放是必要步骤。

## 5. 经典算法

### 5.1 关联规则

- 定义：反映事物之间的相互依存与关联性，可看作 IF–THEN 关系；典型场景是购物篮分析（买面包和黄油的人更可能买鸡蛋）`[原文]`。
- 两个核心指标 `[原文]`：

```text
Support(A,B)    = freq(A,B) / N          # 组合出现的频率
Confidence(A→B) = freq(A,B) / freq(A)    # 买了 A 之后买 B 的概率
```

- Apriori、FP-Growth 在讲义中标注「略」，只讲概念与应用 `[原文]`。

### 5.2 贝叶斯

- 先验概率 P(Y)：看到训练数据前假设 Y 的初始概率；后验概率 P(Y|X)：看到数据 X 后 Y 成立的置信度 `[原文]`。
- 贝叶斯公式：`P(Y|X) = P(X|Y)P(Y) / P(X)`，其中 P(X|Y) 是似然，P(Y) 是先验，P(X) 是边际似然 `[原文]`。
- 朴素贝叶斯：假设属性条件独立，是典型的生成学习方法——先学 P(X|Y) 与 P(Y)，得到联合分布 P(X,Y)=P(X|Y)P(Y)，再求后验 `[原文]`。
- 贝叶斯网络：用有向无环图表示变量间依赖，节点是变量、边是依赖、边旁条件概率表示强弱；学习分结构学习与参数学习 `[原文]`。
- 贝叶斯最优分类器是 NP-Hard（Chickering, 1996）`[原文]`。

### 5.3 支持向量机（SVM）

- 由 Vapnik 提出；优势是高维数据与避免维度灾难 `[原文]`。
- 几何直觉：二维用直线、三维用平面、更高维用超平面分割 `[原文]`。
- 三种由简至繁的模型 `[原文]`：

| 数据情况 | 方法 | 模型 |
| --- | --- | --- |
| 完全线性可分 | 硬间隔最大化 | 线性可分 SVM |
| 近似线性可分 | 软间隔最大化（允许少量错分） | 线性 SVM |
| 线性不可分 | 核技巧 + 软间隔最大化 | 非线性 SVM |

- 讲义提到 VC 维与结构风险最小化，但未展开推导 `[原文]`。

### 5.4 聚类

- 定义：把物理或抽象对象分组为相似对象组成的簇；簇内相似度高、簇间相异度高；距离是最常用的相异度度量 `[原文]`。
- 五类方法 `[原文]`：

| 类别 | 代表算法 |
| --- | --- |
| 划分 | k-means、k-medoids |
| 密度 | DBSCAN、OPTICS、DenClue |
| 层次 | 凝聚/分裂层次聚类；Diana、Agnes、BIRCH、ROCK、CAMELEON |
| 网格 | STING、WaveCluster、CLIQUE、SCI |
| 模型 | EM、SOM、COBWEB |

- 应用：市场细分、文档聚类、图像分割/压缩、特征或词典学习、犯罪热点、保险欺诈、公共交通、IT 资产分组、客户细分、癌症数据、搜索、医疗、药物活性预测等 `[原文]`。

## 6. 高阶算法

### 6.1 集成学习

- 通过构建并结合多个学习器完成任务，又称多分类器系统、基于委员会的学习 `[原文]`。
- 同质集成：个体学习器由同一算法生成，称基学习器；异质集成：由不同算法生成，称组件学习器 `[原文]`。
- 两大类 `[原文]`：

| 类别 | 个体学习器关系 | 代表 | 训练方式 |
| --- | --- | --- | --- |
| Boosting | 强依赖、串行 | AdaBoost、GBDT、XGBoost、LightGBM | 逐轮训练，每轮调整训练集 |
| Bagging | 弱依赖、可并行 | 随机森林 | 子抽样训练多个基模型，再综合 |

- 讲义列出的算法：Random Forest、AdaBoost、GBDT、XGBoost、LightGBM `[原文]`。

### 6.2 深度学习

- 神经元数学模型：对前向输入加权累加 `In = Σ w_i a_i`，再过非线性激活函数 `g`，输出 `Out = g(In)`；神经元越多、非线性映射越复杂 `[原文]`。
- 深层神经网络：包含 2 个以上隐含层；算力提升缓解训练低效，数据增加降低过拟合风险 `[原文]`。
- 与传统 ML 的关键差别：传统方法依赖人工特征工程；深度学习通过多层处理把低层特征转为高层表示，用简单模型完成复杂任务，向「全自动数据分析」前进 `[原文]`。
- CNN：卷积层、pooling 层、全连接层；LeNet（1998，手写数字识别，测试误差 <1%）确立基本组件；AlexNet 证明 CNN 在复杂模型下的有效性，GPU 让训练可行 `[原文]`。
- RNN：对序列数据建模，隐藏层节点有连接，当前输入含上一时刻隐藏层输出；用于 NLP、语音、翻译、在线交易预测等 `[原文]`。
- LSTM：特殊 RNN，解决长序列训练中的梯度消失/爆炸，能在更长序列上保持误差稳定、建立远距离因果联系 `[原文]`。

### 6.3 迁移学习

- 动机：传统 ML 假设训练/测试样本独立同分布且有足够训练数据，现实中往往不成立（股票时效性强、新业务缺数据）`[原文]`。
- 定义：用源域已有知识解决目标域只有少量标注甚至无标注数据的问题，把通用模型迁移到个性化数据 `[原文]`。
- 四种类型 `[原文]`：

| 类型 | 做法 | 例子 |
| --- | --- | --- |
| 样本迁移 | 给源域中与目标域相似的样本更大权重 | 加重相似样本权重 |
| 特征迁移 | 把源域/目标域特征变换到同一空间，使分布一致 | 「好帅」「好漂亮」都映射到「好看」 |
| 参数/模型迁移 | 把源域训练好的模型应用到目标域（如微调预训练网络） | Inception/VGG16 只重训 softmax，几千张图即可 |
| 关系迁移 | 迁移源域中的逻辑/关系结构 | 生物病毒传播 → 计算机病毒传播；师生 → 上司下属 |

- 理论溯源：Judd 的「类化说」——先期学习获得的一般原理可部分或全部用于后期学习；共同要素是迁移的必要前提 `[原文]`。
- 讲义引用吴恩达观点：迁移学习是推动 ML 商业化的重要驱动技术，下一步会迎来商业应用爆发 `[原文，属观点]`。

### 6.4 强化学习

- 定义：从环境状态到行为映射的学习，目标是使动作获得的累积回报最大；介于监督与无监督之间 `[原文]`。
- 基本模型：Agent 按策略（policy）根据状态（state）选择动作（action）；环境返回新状态与奖励（reward）；目标是最大化累计期望回报 `[原文]`。
- 分类 `[原文]`：
  - 基于模型（Model-based）vs 无模型（Model-free）：是否依赖对环境（马尔可夫随机过程）的先验知识或建模；
  - 基于价值（Value-based，对价值函数建模，用策略优化定理求解）vs 基于策略（Policy-based，对策略函数建模，用策略梯度定理求解）。
- AlphaGo 三大法宝：深度学习（感知棋面）+ 强化学习（自我博弈）+ 蒙特卡洛树搜索（采样学习）`[原文]`。

## 7. 工业 4.0 与智能制造背景

- 智能制造能力成熟度：多数制造企业仍在第 2 级「规范级」或第 3 级「集成级」`[原文]`。
- 工业 4.0 的七个特征 `[原文]`：制造中采用物联网与服务互联网；满足个性化需求、面向客户的 App 商店；人机一体化协同创造；信息集成的优化决策；资源有效利用与绿色可持续；通过新服务创造价值；人与制造系统之间的互动协作。
- 目标：多品种小批量定制化同时实现敏捷生产；基于 ICT 实现智能工厂与绿色生产；CPS/IoT/互联网产生大数据，通过集成处理大数据实现优化高效制造；基于 CPS 的工业辅助培养新一代工人 `[原文]`。
- 企业是创新主体；数字化、智能化转型的落点是智慧工厂、机器学习与降本增效 `[原文]`。
- 案例：友达光电（苏州）的内生型、全方位数字化转型；徐工机械的「数制融合，智慧赋能」`[原文，讲义未给细节]`。
- MSI 实战讨论题 `[原文]`：现有信息化系统有哪些、互联互通如何、达到成熟度几级、数据如何采集/存储/分析、如何用这些数据提高生产效率/市场份额/总体效益。

## 8. 怎么用这份讲义

1. **做算法选型时先用三视角表**：先定任务（分类/回归/…），再定范式（有没有标签、是否序贯决策），最后才在概率/几何/逻辑/网络四类模型里选具体算法。
2. **不要用算法清单代替问题定义**：讲义自己说算法数千种；把业务目标、标签、数据代表性、评价指标先定清楚，比换模型更有效。
3. **工业场景优先看数据条件**：有没有标签、故障样本多少、特征是否可解释，决定了你能否用监督学习、迁移学习或小样本方法。
4. **组织条件是前提**：数据、技术、投入、一把手工程缺一不可；纯算法项目容易死在数据和跨部门协作上。
